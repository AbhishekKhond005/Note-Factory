## How to use this roadmap

Start from `00-start-here`, then go folder by folder in order.
The most important areas for strong Java understanding are:

* `02-oop-fundamentals`
* `03-java-method-behavior`
* `05-exceptions-and-errors`
* `06-collections-and-generics`
* `08-memory-and-jvm`
* `10-concurrency-and-multithreading`
* `13-spring-and-backend-path`
* `14-dsa-in-java`

This structure is meant to show not just what to study, but how the topics connect to each other.

## The most important hidden idea

A lot of your confusion comes from this one split:

* **compile time** = Java checks if your code is legal
* **runtime** = the JVM decides what actually happens

That split is the backbone of almost every confusing Java rule.
